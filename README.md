# Auto Clicker (أندرويد)

تطبيق نقر تلقائي بسيط، مكتوب من الصفر بـ Kotlin بدون أي مكتبات خارجية.

## التشغيل
1. افتح المجلد في **Android Studio** (سيُنشئ gradle wrapper ويحمّل الاعتماديات تلقائياً).
2. وصّل هاتفك (تصحيح USB) أو شغّل محاكياً واضغط Run.
3. على الهاتف: افتح التطبيق ← «فتح إعدادات إمكانية الوصول» ← فعّل **Auto Clicker**.
4. ستظهر لوحة تحكم ودائرة حمراء فوق كل التطبيقات.

## الاستخدام
- اسحب الدائرة الحمراء إلى مكان النقر.
- `+` / `−` تغيّر الفاصل بين النقرات (50 ملّي ثانية إلى 10 ثوانٍ، الخطوة 50).
- `▶` تشغيل، `■` إيقاف، الرقم الأخير عدّاد النقرات، `✕` إغلاق الخدمة.
- اسحب اللوحة من المقبض `⠿`.

## ملاحظات
- يحتاج Android 7.0 (API 24) أو أحدث لأن `dispatchGesture` غير متاح قبله.
- لا يستخدم إلا إذن خدمة إمكانية الوصول، ولا يطلب إنترنت ولا يجمع بيانات.
- بعض التطبيقات والألعاب قد تمنع أو تتجاهل النقرات الآلية؛ هذا من جهتها.
- الكود في `app/src/main/java/com/example/autoclicker/ClickerService.kt`.
